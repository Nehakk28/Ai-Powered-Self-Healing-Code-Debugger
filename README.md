# Ai-Powered-Self-Healing-Code-Debugger

A Django-based AI debugger that analyzes code errors and provides smart debugging suggestions.

## Features
- AI-powered error analysis
- Code debugging assistance
- User authentication
- Chat and dashboard views

## Installation
```bash
git clone <repo-link>
cd ai_debuger
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
